확정(U)은 사용자가 직접 정한 사항이고, 가정(A)은 답이 없어 임시로 둔 값을 스펙 단계에서 승인받은 것이다.

E2E 플로우

앱 홈에서 수리예약까지, 화면 6개

노드를 클릭하면 해당 화면의 정의로 이동한다. 선 색은 결과를 수리예약에 첨부하는지를 뜻한다.

결과 첨부 함 결과 첨부 안 함 해당 없음 뒤로가기
선이 겹치는 곳은 교차일 뿐 연결이 아니다. 노드 8개, 이동 17개.

수리예약(E-01)에 도달하는 경로는 4가지다 — S-01 건너뛰기, S-05 중단, S-06 건너뛰기, S-03 수리예약 계속. S-03 경로만 결과를 첨부한다. 모든 화면에서 E-01 또는 앱 홈으로 나갈 수 있어 막다른 화면은 없다.

화면 탐색기

화면 6개의 정의와 이동

화면을 선택하면 목적·진입 조건·표시 요소·사용자 행동이 나온다. ← →로 이동할 수 있다. 카피는 확정하지 않았고 와이어프레임이 아니라 텍스트 정의다.

화면 이동표

17행. 결과 첨부 여부로 걸러 볼 수 있다.

결과 시연

분야별 결과가 전체 상태를 정하는 방식

분야별 결과를 바꿔 보면 S-03의 전체 상태, S-06 이동 여부, 안내 표시가 어떻게 달라지는지 확인할 수 있다.

규칙 시연용이다. 실제 화면 목업이 아니며, 기획안 5.3(전체 상태 산정), R-01·R-03~R-05, F-01을 그대로 보여준다. 전체 상태는 이상 발견 > 확인 불가 > 정상 순으로 우선 적용한다.

진단 분야

7개 분야와 결과 표기

이 장은 화면에 무엇이 어떻게 표기되는지만 정한다. 판정 로직과 기준값은 범위 밖이다.

정품확인(D-03)과 기능 진단(D-06·D-07)은 별개다. D-03은 배터리·카메라·디스플레이 등 중요부품이 정품인지, D-06·D-07은 카메라·디스플레이가 동작하는지를 본다. S-01·S-02·S-03의 표기 순서는 D-01→D-07로 통일한다.
